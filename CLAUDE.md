# CLAUDE.md

Проект: примерочная татуировок (см. SPEC.md). Next.js + React 19 + TypeScript (strict) + Three.js (react-three-fiber) + Tailwind. MVP без бэкенда; PostgreSQL + Drizzle только на этапе 2.

## Как не повторить прошлую ошибку (проект застрял в «каше»)
- Сначала `SPEC.md`, потом код. Любая фича вне MVP из SPEC.md п. 2 не добавляется без обновления спеки.
- Сначала вертикальный срез (модель + слой + клик + компоновка), потом остальное.
- Бэкенд не трогать, пока MVP не выпущен.
- Тату живёт в UV-пространстве; состояние — одно дерево в `src/state/store.ts`. Не хранить копии состояния в компонентах.
- Типы данных выводятся из Zod-схем в `src/schema/project.ts`; не дублировать их вручную. Внешние данные (файл проекта, ссылка) всегда проходят через Zod.
- Логику (compose, serialize, params) держать в чистых функциях с юнит-тестами, не внутри React-компонентов.
- Никаких `any` и `// @ts-ignore`.
- Не заявлять «работает» без запуска тестов; показывать фактический вывод.
- Не оставлять мёртвых папок и дублей (например, вложенная `3d-body-editor/`, старые файлы шаблона Vite).
- Каждый ассет (модель, тату) с лицензией в `LICENSES.md`.

## Команды
- `npm run dev` — разработка
- `npm run lint` и `npm run typecheck` — перед каждым коммитом
- `npm test` — Vitest
- `npm run e2e` — Playwright
